Pembaruan Bobot Jaringan Saraf Tiruan

Rumus yang digunakan AI untuk belajar dari kesalahan (Error Minimization) menggunakan algoritma Gradient Descent.

// 1. Hitung Error (Mean Squared Error)
E = 1/2 ∑ (Target - Output)²

// 2. Hitung Gradien menggunakan Aturan Rantai (Chain Rule)
Δw = -η * (∂E / ∂w)
   = -η * (∂E / ∂Output) * (∂Output / ∂Net) * (∂Net / ∂w)

// 3. Update Bobot (Weight)
W_baru = W_lama + Δw

def shors_algorithm(N):
    # 1. Pilih angka acak 'a' < N
    a = random_choice(2, N-1)
    
    # 2. Cari FPB(a, N) klasik
    if gcd(a, N) != 1:
        return gcd(a, N)
        
    # 3. Kuantum: Temukan periode 'r' fungsi f(x) = a^x mod N
    r = quantum_period_finding(a, N)
    
    # 4. Jika 'r' ganjil, ulangi. Jika genap, hitung faktor:
    faktor_1 = gcd(a^(r/2) - 1, N)
    faktor_2 = gcd(a^(r/2) + 1, N)
    
    return (faktor_1, faktor_2)
